# Adaptive Lesson Designer｜可操作原型 v0.1

**狀態：可測試的教師課程設計草案工具（BLUEPRINT），不是正式教材產生器。**

本原型將已核准的 [Adaptive Lesson Design 原則](ADAPTIVE_LESSON_DESIGN.md) 落成離線、手機／iPad 可使用的活動建議頁。

## 開啟方式

在 GitHub Pages 合併部署後：`demos/adaptive-lesson-designer.html`。

在電腦本機測試可用靜態伺服器（從倉庫根目錄）：

```bash
python -m http.server 8000
```

再開啟 `http://localhost:8000/demos/adaptive-lesson-designer.html`。不需要 API 金鑰、第三方字型、CDN、帳號或雲端服務。

## 實際可操作功能

1. 選擇 Starter、Unit 1、Unit 2、閱讀、拼字或自訂教學主題。
2. 修改教學目標、資料來源與來源核對狀態；選核心／補救／進階及學習負荷、時間。
3. **規則選活動而不是固定模板**：例如 Starter be → 主詞對照＋新句應用；Unit 1 家庭關係 → 關係圖＋對話判斷；拼字 → 聽音切分＋無提示提取。
4. 可手動**移除／新增／調整順序**，並查看「為什麼選／怎麼進行／提示何時撤除」；不強制四大活動全選。
5. 來源狀態選「來源不足」，或缺來源／目標，會 **BLOCKED** 並停止生成，列出缺口（最多三項）。
6. 印出 A4 教師教學設計及證據記錄頁；或匯出 JSON 設計草案。

## 重要界線

- 是 **BLUEPRINT**：產生的活動是教學流程卡，不是題目、答案、經課本核對的學生練習或正式已核准課程。
- 「教師已核對」只是教師自行宣告，**程式沒有能力驗證原始來源是否正確**。使用者輸入的來源資訊不會被當成自動核准依據。
- 「未曝光新題獨立檢核」與「延後無提示提取」保留在證據計畫中；現階段不自動建立 Gate 題目，也不評估學生是否學會。
- 不可用提示下的成功認定獨立掌握。需教師另核對原始教材、詞彙及出版 QA。
- 無登入、無雲端同步、無 AI 呼叫、無資料持久化；不蒐集學生姓名或健康資料。
- 此 PR **不修改**現有教學紀錄 PWA、Service Worker 或正式的 Stable Core。

## 使用例

| 主題 | 預設推薦（30 分鐘，核心路線） | 不會硬塞 |
|---|---|---|
| Starter｜主格代名詞與 be | 主詞對照 → 新句應用 | 名詞分類 |
| Starter｜姓名與年齡 | 說話者角色卡 → 短對話判斷 | 無關插圖 |
| Unit 1｜人物關係 | 家族關係圖 → 短對話判斷 | 單複數配額 |
| Unit 2｜Where | 物品定位圖 → 情境判斷 | 拼字故事 |
| 閱讀 | 回文定位 → 情境判斷 | One or Many |
| 拼字 | 聽音切分 → 無提示拼字 | 每字都做助記故事 |

**以上是活動類型匹配示例，不聲稱單元題目已正式 Source Lock。**

## 測試

純 JS 決策邏輯（Node.js 內建斷言，無 npm）：

```bash
node tests/adaptive-lesson-rules.test.cjs
```

本次本機測試：18 項規則測試通過。另以 Chromium / Playwright 完成桌面與 390px 觸控尺寸的瀏覽器互動檢查，包括主題切換、活動增刪與排序、來源 BLOCKED、HTML 輸入跳脫、A4 列印與 JavaScript 錯誤檢查；無 JS 錯誤。列印檔為 **A4 直式、2 頁**，另經 PDF 轉圖確認沒有頁面剪裁或中文字亂碼。

**仍待測試：** 實際 iPhone／iPad Safari 操作、GitHub Pages 線上部署及實際教學適用性。僅完成本機功能測試，並未驗證任何學生的學習成效。
