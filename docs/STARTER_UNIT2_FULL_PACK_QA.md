## 重要教材政策

- 以使用者上傳的《學校課本Starter & Unit 1.pdf》以及《Unit 2.pdf》界定**本次內容範圍**，其他參考書只供對照，不能覆蓋原課本。
- 不把已作答或訂正過的頁面視作獨立掌握證據。
- 作答有輔助只計為 guided practice。撤提示後要以未曝光平行新題複查；延後保留需記錄實際間隔天數。
- 不將 46 個知識點出題存在誤認為學生已學會，知識點活動覆蓋與學習成效是兩條不同判定軸。
- 課本 Unit 1 的職業構詞 `-er` 屬 Extension；教師未確認上課進度前，只能作可選補充。
- 語音題、口說能力只保留任務建議／教師觀察欄，不作沒有音訊證據的正式聽力答案。

## 可重現檔案

1. `author_data.py`：Source Matrix、46 知識點、185 題題庫與 65 項 Word Bank 的單一資料源；從原 PR #8 `legacy_subject_be.items.json` 保留原 16 題。
2. `unit_scope_item_bank.json`：從單一資料源輸出的結構化資料，可供檢索與題號追溯。
3. `render_pack.py`：同源輸出學生主練習、分單元、檢核、延後、教師解析、答案速查、詞彙與來源對照 HTML。
4. `print_qa.py`：使用可用的本機 Chromium／Playwright 印成 A4 PDF，檢查每頁文字 overflow 及 A4 尺寸。
5. `test_pack.py`：跨檔字型、頁數、題號、來源、版本、一致性與答案洩漏的核對。

如欲執行 HTML 生成（不需要外部 API）：

```bash
python author_data.py
python render_pack.py
```

A4 PDF 列印需安裝 Chromium、Python Playwright、PyMuPDF；不必部署雲端或連接學生個資。所附 PDF 均已在本次環境預先輸出。
